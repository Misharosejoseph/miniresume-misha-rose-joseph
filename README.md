# Mini Resume Collector API

A simple RESTful API built using FastAPI to collect and manage candidate resume details.  
This application performs input validation, stores data in memory, and exposes structured REST endpoints.

---

## 🚀 Tech Stack

- Python 3.10+
- FastAPI
- Pydantic
- Uvicorn
